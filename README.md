# All Hearts Aflame

Website for All Hearts Aflame, LLC (Jolie Vogliardo), served at https://allheartsaflame.com

A static site generated by `contractweb` from `companies/all_hearts_aflame.json` (template: `ministry`).
Edit the content there and regenerate; do not hand-edit the generated pages.

- `index.html`, `give/`, `references/`, `thankyou/` - the pages (the last three are not linked from the menu)
- `assets/` - logo and photos; `s/` - PDFs and audio (same `/s/` addresses the previous site used)
- `CNAME` - tells GitHub Pages which domain to serve
